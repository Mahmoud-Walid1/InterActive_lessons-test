# 📚 دليل مهندسي المحتوى التفاعلي (Interactive Lessons Framework)

أهلاً بكم في فريق التطوير. مهمتكم هي بناء ونقل الدروس التفاعلية بصيغة معيارية تضمن أعلى أداء وتوافقية مع المنصة التعليمية.

---

## 🛠️ قواعد العمل الأساسية (Strict Guidelines)

1. **الاعتماد على القالب (Template Based):**
   - ممنوع إنشاء هيكل عشوائي من الصفر.
   - كل درس يبدأ بنسخ المجلد `template/` بالكامل إلى المسار المناسب.
2. **عزل الكود (Scoped Code):**
   - كود الـ CSS بالكامل يجب أن يكون داخل الكلاس الرئيسي:
     `.interactive-lesson-container { ... }`
   - يمنع تماماً استخدام Global Variables في الـ JavaScript. استخدم دائماً دالة مغلقة (IIFE) أو كلاس مستقل.
3. **الأصوات والميديا (Media Standards):**
   - صيغة الأصوات المعتمدة: `.mp3` فقط، بمعدل بت لا يتجاوز `128kbps`.
   - الصور بصيغة `.webp` أو `.svg` فقط، وتوضع حصراً داخل مجلد `assets/`.
4. **ملف البيانات (`lesson.json`):**
   - يجب ملء بيانات الدرس بدقة (معرف الدرس `lessonId`، الصف `gradeId`، المادة `subjectId`).

---

## 📂 مسار تسليم الدروس (Folder Structure)

يتم تسليم كل درس داخل مساره الصحيح بالشكل التالي:
`lessons/grade-[الرقم]/[اسم_المادة]/[معرف_الدرس]/`

مثال:
`lessons/grade-1/science/g1-sci-01/`
