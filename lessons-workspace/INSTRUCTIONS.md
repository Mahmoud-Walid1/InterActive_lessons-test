# 📘 دليل مهندس المحتوى والمعلم (Content Workspace Guide)

مرحباً بك في مستودع إعداد وتطوير الدروس التفاعلية!
تم تصميم هذه البيئة لتكون **معزولة، خفيفة، وسهلة الاستخدام تماماً**؛ لا تتطلب منك تثبيت أي برامج وسيطة أو حزم برمجية (`node_modules`)، وتعمل بالكامل بمعايير الويب القياسية لضمان أقصى سرعة وأعلى توافق.

---

## 📁 هيكل المستودع (Workspace Structure)

```text
lessons-workspace/
├── template/                  # القالب الأساسي النموذجي للدرس
│   ├── index.html            # صفحة العرض المعزولة
│   ├── style.css             # التنسيقات البصرية
│   ├── script.js             # المحرك التفاعلي ونظام الصوتيات
│   ├── lesson.json           # ملف بيانات الدرس
│   └── assets/
│       ├── audio/            # ملفات الأصوات (.mp3, .wav)
│       └── images/           # ملفات الصور والأيقونات (.svg, .png, .webp)
├── lessons/                   # مجلدات تسليم الدروس مصنفة حسب الصفوف
│   ├── grade-1/              # الصف الأول الابتدائي
│   ├── grade-2/              # الصف الثاني الابتدائي
│   ├── grade-3/              # الصف الثالث الابتدائي
│   ├── grade-4/              # الصف الرابع الابتدائي
│   ├── grade-5/              # الصف الخامس الابتدائي
│   └── grade-6/              # الصف السادس الابتدائي
├── preview/
│   └── index.html            # أداة المعاينة الفورية وفحص الجاهزية
├── .gitignore                # استبعاد الملفات غير الضرورية
└── INSTRUCTIONS.md           # هذا الدليل الإرشادي
```

## 🚀 خطوات إنشاء درس جديد (خطوة بخطوة)

### الخطوة 1: نسخ مجلد القالب
1. انسخ مجلد `template` كاملاً.
2. توجّه إلى مجلد الصف المستهدف داخل `lessons/` (مثال: `lessons/grade-4/`).
3. الصق المجلد وأعد تسميته باسم الدرس بالإنجليزية بأحرف صغيرة ومفصولة بشرطة (مثال: `fractions-intro` أو `animal-groups`).

### الخطوة 2: تعديل محتوى `lesson.json`
افتح ملف `lesson.json` وقم بتعديل البيانات الأساسية:
- `"id"`: معرف فريد للدرس (مثال: `"lesson_grade4_fractions"`).
- `"title"`: عنوان الدرس بالعربية (مثال: `"مفهوم الكسور الاعتيادية"`).
- `"gradeId"`: الصف المخصص (`"grade_1"` إلى `"grade_6"`).
- `"subjectId"`: المادة (`"science"`, `"math"`, `"arabic"`, `"studies"`, `"english"`).
- `"description"`: نبذة توضيحية عن الدرس.
- `"slides"`: مصفوفة الشرائح التفاعلية.

## 🎨 أنواع الشرائح المدعومة (Slide Types)

يمكنك استخدام 4 أنواع رئيسية من الشرائح داخل مصفوفة `"slides"`:

### 1. شريحة الشرح (`"type": "explain"`)
مخصصة لتقديم المفاهيم مع نقاط وشارات وأمثلة:
```json
{
  "id": "slide_intro",
  "type": "explain",
  "eyebrow": "مقدمة الدرس",
  "title": "ما هي الكسور؟",
  "subtitle": "شرح مبسط لمفهوم الكسر وأجزائه.",
  "mascotTip": "نصيحة الروبوت التي تظهر أسفل العنوان للمتعلم!",
  "sceneAnimation": "bounce",
  "traits": [
    "البسط يمثل الأجزاء المأخوذة",
    "المقام يمثل إجمالي الأجزاء"
  ],
  "examples": [
    { "emoji": "🍕", "name": "شريحة بيتزا" },
    { "emoji": "🥧", "name": "فطيرة مقسمة" }
  ]
}
```

### 2. شريحة البطاقات الاستكشافية (`"type": "interactive_reveal"`)
مخصصة للبطاقات القابلة للنقر لكشف التفاصيل وسؤال التحدي:
```json
{
  "id": "slide_cards",
  "type": "interactive_reveal",
  "eyebrow": "اكتشف وتفاعل",
  "title": "مجموعات الأشكال",
  "groups": [
    { "id": "g1", "emoji": "🔺", "name": "المثلث", "detail": "شكل هندسي له ثلاثة أضلاع وثلاث زوايا." }
  ],
  "reveal": {
    "question": "اضغط هنا لكشف معلومة الذكاء",
    "answer": "مجموع زوايا أي مثلث يساوي 180 درجة دائماً!"
  }
}
```

### 3. شريحة السؤال والاختبار (`"type": "quiz"`)
مخصصة لاختبار فهم التلميذ مع خيارات ونظام التحقق الفوري:
```json
{
  "id": "slide_quiz_1",
  "type": "quiz",
  "eyebrow": "سؤال التحدي",
  "title": "احسب الكسر الصحيح",
  "quiz": {
    "id": "q1",
    "emoji": "🎯",
    "name": "سؤال الكسور",
    "question": "إذا قسمنا شكلاً إلى 4 أجزاء وأخذنا جزءاً واحداً، فما هو الكسر؟",
    "choices": [
      { "id": "c1", "text": "1/4 (ربع)", "isCorrect": true },
      { "id": "c2", "text": "1/2 (نصف)", "isCorrect": false },
      { "id": "c3", "text": "3/4 (ثلاثة أرباع)", "isCorrect": false }
    ]
  }
}
```

### 4. شريحة الإنجاز والتكريم (`"type": "summary"`)
مخصصة لنهاية الدرس وعرض النجوم ومكافأة التلميذ:
```json
{
  "id": "slide_finish",
  "type": "summary",
  "eyebrow": "لوحة الشرف",
  "title": "أحسنت يا بطل! أتممت الدرس بنجاح",
  "subtitle": "لقد تعلمت مفهوم الكسور واجتزت التحدي بتفوق!"
}
```

## 🔍 كيف تعاين وتختبر درسك قبل التسليم؟ (المعاينة الفورية)

لست بحاجة لتثبيت أي سيرفر! اتبع الآتي:
1. افتح ملف `preview/index.html` في أي متصفح (Chrome, Edge, Firefox, Safari).
2. ستظهر لك واجهة المعاينة الفورية المتطورة.
3. **اسحب وأفلت** ملف `lesson.json` الخاص بدرسك في المربع المخصص، أو اضغط على زر **"فتح ملف lesson.json"**.
4. تأكد من ظهور علامات الصح الخضراء في قائمة **"فحص جاهزية الدرس (Pre-flight)"**.
5. جرب التنقل بين الشرائح، اضغط على البطاقات، وجرب حل السؤال والتأكد من انطلاق النغمات.

## 🔊 نظام الأصوات والمؤثرات (Audio Rules)

* **الصيغة المدعومة:** يفضل وضع ملفات الصوت بصيغة `.mp3` داخل مجلد `assets/audio/`.
* **المولد التلقائي الذكي (Synthesizer Fallback):** في حال عدم إضافة ملف صوت مخصص، يعمل محرك المتصفح تلقائياً على توليد نغمات موسيقية عبر ترددات Web Audio API لضمان عدم توقف الدرس أبداً.

## 📤 آلية تسليم التعديلات (Git Workflow)

1. أنشئ فرعاً جديداً (Branch) لدرسك:
   ```bash
   git checkout -b content/grade-4-fractions
   ```
2. تأكد أن عملك بالكامل داخل مجلد الصف المناسب داخل `lessons/`.
3. قم بعمل Commit و Push للفرع الخاص بك:
   ```bash
   git add .
   git commit -m "feat(content): add grade 4 fractions lesson"
   git push origin content/grade-4-fractions
   ```
4. افتح طلب دمج (Pull Request / Merge Request) للمدير، حيث سيقوم النظام تلقائياً باعتماد الدرس وتشفيره وحزمه للمنصة الرئيسية.
